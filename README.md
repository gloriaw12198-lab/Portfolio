# Creative Portfolio Platform

A modern Single Page Application (SPA) built with React that allows users to explore creative projects, search projects dynamically, and add new portfolio items through an interactive form.
## Project Overview

This project was developed as part of a React SPA summative lab. The application showcases a responsive portfolio platform for a creative agency or personal brand.

Users can:

- View projects
- Search projects dynamically
- Add new projects
- Experience a responsive modern UI

---

## Features

### Landing Page
- Modern hero section
- Responsive layout
- Project showcase cards

### Dynamic Search
- Search projects instantly
- Real-time filtering using React state

### Add New Projects
- Users can submit:
  - Project title
  - Description
  - Image URL
  - Category

### Responsive Design
- Mobile-friendly grid layout
- Modern card-based interface



## Technologies Used

- React
- Vite
- JavaScript
- CSS3
- React Hooks (`useState`)
- Git & GitHub
